# SDSC Summer Institute 2026 — Instructor Guide

## Laptop Requirements for Attendees

Attendees only need an **SSH terminal and a web browser** on their laptops. Administrative privileges are **not** required.

- All hands-on activities must run on **Expanse**, either via SSH or through the [Expanse User Portal](https://portal.expanse.sdsc.edu).
- Do **not** require attendees to install or run any software on their local machines.
- If your session has requirements that go beyond what Expanse can provide, contact Andrea Zonca (zonca@sdsc.edu) as soon as possible so we can find a solution.
