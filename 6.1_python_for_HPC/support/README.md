# Support files

Students do not need to open this folder during the live lesson.

- [`condaenv_scratch/`](condaenv_scratch/README.md) contains the
  `python_expanse.slrm` batch example and the `node_info.py` diagnostic.
  Both use the shared `pythonhpc` conda env installed by
  `../setup_python_env.sh`.
- [`python_singularity/`](python_singularity/README.md) is an optional
  container workflow for instructors and learners who want additional
  practice.

The numbered folders in the lesson root follow the teaching order.
