# Support files

Students do not need to open this folder during the live lesson.

- [`condaenv_scratch/`](condaenv_scratch/README.md) copies the prepared Python
  environment to each compute node. The Dask worker script uses this support
  code.
- [`python_singularity/`](python_singularity/README.md) is an optional container
  workflow for instructors and learners who want additional practice.

The numbered folders in the lesson root follow the teaching order.
