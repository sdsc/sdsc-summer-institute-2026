# 2025 MNIST example snapshot

This directory is a source snapshot of the project used for the 2025 version of
this session.

- Original repository: <https://github.com/ofgarzon2662/mnist_ae>
- Snapshot commit: `c5a56da`
- Snapshot date: July 2026
- Purpose: preserve the notebooks, generated Python package, tests, packaging
  configuration, and GitHub Actions examples referenced by the presentation.

The downloadable raw MNIST files under `nbs/data/` were excluded from this
snapshot. The notebooks and training code download MNIST when needed. Local
virtual environments, caches, build products, and the original `.git`
directory were also excluded.

The snapshot is historical reference material. The shorter hands-on exercise
for the 2026 session is in `../tutorial/`.
