# Skydiver tutorial project

This small nbdev project models vertical free fall with quadratic drag. The
notebook in `nbs/` is the source for `skydiver/physics.py`. Tests protect the
model's physical assumptions, and `skydiver/cli.py` provides a fresh-process
entry point.

This directory is a **seed project**. Students copy its contents into a new,
empty repository they own; they do not fork the Summer Institute repository.

When viewing this project inside the course repository, start with the parent
[tutorial instructions](../README.md). Once copied into a student's repository,
use the course's
[PyPI and Expanse workflow](https://github.com/ofgarzon2662/sdsc-summer-institute-2026/blob/main/5.1_best_practices_for_scientific_computing/resources/expanse-pypi-workflow.md)
before publishing or running on Expanse.
