## Accounts, Login, Environment, Running Jobs and Logging into Expanse User Portal
**Presenter":** [Marty Kandes](https://github.com/mkandes)

In this virtual session, we'll familiarize you with logging into Expanse with your training account both via the Expanse User Portal and directly via SSH.

### Getting your training account and password

You should receive an email with your training account credentials prior to the institute.

### Login to the Expanse User Portal

Once you have your training account username and password, please open your favorite web browser to the [Expanse User Portal](https://portal.expanse.sdsc.edu/training) and attempt to login.

### Login to Expanse via SSH

After you're done exploring the Expanse User Portal, please also attempt to login directly to Expanse via SSH:
```
ssh trainXXX@login.expanse.sdsc.edu
```
